Propagación de Cabecera X-Correlation-ID

Ciclo de vida de una petición HTTP desde su creación en el cliente React, tránsito por YARP, enriquecimiento en LogContext y correlación unificada en Seq.

ORIGEN EN EL CLIENTE

Generación & Inyección

  • El frontend crea un GUID único con crypto.randomUUID().
  • Inyecta el encabezado X-Correlation-ID en la petición.
  • Permite rastrear la experiencia del usuario desde el navegador.
  • Permite emparejar la respuesta HTTP con la traza de auditoría.

PROPAGACIÓN & ENRIQUECIMIENTO

YARP & Middleware .NET

  • YARP inspecciona la cabecera y la transfiere al destino.
  • CorrelationIdMiddleware inserta el ID en LogContext.
  • Cada llamada logueada incluye automáticamente el CorrelationId.
  • La cabecera se devuelve en la respuesta HTTP final al cliente.

VISIBILIDAD CENTRALIZADA

Agregación en Seq

  • Streaming asíncrono vía Serilog Seq Sink (:5341).
  • Filtro instantáneo: @Properties['CorrelationId'] == '...'.
  • Visualización cronológica del camino Gateway → Servicio → DB.
  • Diagnóstico inmediato ante excepciones o latencias anormales.
