Topología de Contenedores Docker Compose

Aislamiento de red interna (microservices-net), contenedores de servicios versionados, persistencia de volúmenes y puertos mapeados.

RED BRIDGE AISLADA

microservices-net

  • Los microservicios no exponen puertos directamente al host.
  • Resolución DNS automática mediante el nombre del contenedor.
  • YARP actúa como el único proxy que cruza la frontera de red.

VOLÚMENES NOMBRADOS

Persistencia de Datos

  • postgres_data montado en /var/lib/postgresql/data.
  • seq_data montado en /data para retención de trazas.
  • Sobrevive a detenciones y reinicios de contenedores.

GESTIÓN DE RECURSOS

Orquestación Local

  • Comando unificado: docker compose up -d.
  • Dependencias declaradas con depends_on y healthchecks.
  • Entorno idéntico para desarrollo y pruebas de integración.
